# convex-teams

The Convex teams component is under active development at [clipinfit/convex-teams](https://github.com/clipinfit/convex-teams).

This `0.0.0-development.0` package claims the project name while the initial component release is prepared. It contains this notice and the Apache-2.0 licence. It has no runtime API and must not be used as a working Convex component.

The upcoming component provides workspace membership, ownership transfer, preferences, and invitation integration through `convex-invite`. See the repository for implementation status and release checkpoints.
